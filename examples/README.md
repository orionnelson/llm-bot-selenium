# Generated fixture examples

Generated by `run_demo.py` against synthetic dependency-timeout fixtures. These are not real Dynatrace workflows and contain no sessions or credentials.

- `investigation-explanation.json`: visited pages/queries, evidence, before/after hypotheses, ablation retention and a useful throttling rule-out.
- `validated_fixture_skill.json`: parameterized workflow validated on a held-out synthetic fixture only.
- `learned_dependency_skill.py`: generated Selenium module; `run(driver, base_url, context, incident)` collects fresh evidence through the loopback mock adapter and applies the independent verifier. Requires an isolated caller-owned Selenium driver. Real-browser execution remains NOT RUN in this environment.

Do not change `status` to promote a real workflow. Production skill approval and identity/SSO integration are out of scope for these files.
